## Public independent-adapter tests

```bash
python3 -m unittest discover -s tests -v
```

Fourteen tests cover:

- Named VCF tumour selection; deliberately renamed output specimen IDs;
  rejection of a missing VCF tumour column instead of guessing another one.
- Actual ref/alternate `AD` mapping and multiallelic splitting.
- PCGR gene/protein annotation, with unannotated variants retained explicitly.
- PASS, CN-zero, missing-segment/count and symbolic-allele filtering.
- Unique IDs, sex concordance, unusual germline-CN review and overlapping-CN
  rejection.
- Independent one-row Cluster/Timing SIFs and runtime path mapping.
- The legacy allele-CN bridge's inverse relation, including high-copy inputs.
- Preservation of existing preparations.
- Native/legacy comparison headers, unknown-presence retention, specimen
  mismatch, invalid probability and header-only output rejection.

GitHub Actions runs these independent tests and the fabricated-data input
conversion on Python 3.12. The integrated repository also runs the 22 core
regression tests and the full synthetic three-stage smoke test. These are
compatibility/regression checks, not a biological benchmark.

## Historical local synthetic integration smoke test

On 2026-10-30, the scripts and core completed a local synthetic integration
test. The core's **47 file hashes matched** the accepted sex-aware V2 snapshot
packaged in branch `sash-purple-sexaware`.

```bash
PHYLOGIC_ROOT=/path/to/authorized/core \
PYTHON=/path/to/python3.12 bash examples/run_demo.sh
```

The run used fabricated male/female samples generated by `make_demo.py`:

| Check | Fabricated male | Fabricated female |
|---|---:|---:|
| Prepared input mutations | 304 | 304 |
| Cluster output mutations | 303 | 304 |
| Cluster groups | 2 | 2 |
| Timing event-QC records | 13 | 11 |
| Pairwise comparison rows | 78 | 55 |
| Cluster sex-CN QC rows | 5 | 0 |

Both Cluster runs used 250 iterations;
Timing used `comparison_method=original`. Mutation and cluster CCF arrays
were finite, nonnegative 101-bin posteriors with total mass one, and Timing
comparison probabilities were finite and normalised.

The two fabricated specimens' comparison tables were aggregated into one
**synthetic smoke-test cohort**, with 133 rows. A deliberately short native
LeagueModel run completed with two samples, **2 permutations, 10 seasons and
13 automatically selected events**. Both native PDFs were generated, and
saved-model parameter values/score lengths were checked. These are not the
production 500/200 settings and are not an ecDNA group comparison.

The compact, patient-free receipt is
[`synthetic_smoke.json`](../provenance/synthetic_smoke.json). Recheck an owned
demo run using:

```bash
python3 workflow/verify_demo.py \
  --demo-root /path/to/your/demo \
  --phylogic-root /path/to/authorized/core \
  --report /path/to/your/demo/smoke_validation.json
```

The local smoke test ran on macOS arm64 / Python 3.12.2 with the versions
recorded in that receipt. The separate Linux dependency freeze describes
the existing analysis container; **it is not the local smoke-test runtime**.
Numerical identity across these environments is not asserted.

This checks input compatibility and obvious propagation failures. It does
not benchmark biological accuracy, validate all WGD/high-copy states, or
replace production cohort acceptance.
The 22 core regression tests are included in this repository's CI;
study-specific patient pilot/cohort gates remain separate.
